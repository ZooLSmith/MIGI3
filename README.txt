	== Installation ==
		
		+ Extract to CS:GO's folder:
			
			- Right Click  "Counter-Strike: Global Offensive" in Steam.
			- Properties...
			- LOCAL FILES
			- BROWSE LOCAL FILES...
		
		+ Drag and drop MIGI.EXE in the folder.
		
		+ Right click MIGI.EXE -> Run as administrator (only the first time)
		
	== Install Addons ==
		
		+ Launch MIGI
		
		+ Click "Go to Addons"
		
		+ Depending on addons:
		
			- M_ VPK addon:
				. Drag and drop the VPK file into the addons folder.
			
			- P_ Folder addon:
				. Decompress the Zip/Rar/7z file if compressed into the addons folder.
				. Path should then be "/migi/csgo/addons/p_xxxxxx/".
				
		+ Click "Generate MIGI"
		
		+ Click "Launch CS:GO with MIGI addons"
